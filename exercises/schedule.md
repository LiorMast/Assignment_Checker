# לוח זמנים לתרגילים

Exercises are published in the morning and due at midnight (Israel time).
`npm run fetch -- <key>` uses these dates as the defaults for `--since` (publish date) and `--deadline` (the whole due day counts: a mail is late from 00:00 of the next day).
Keep full dates (YYYY-MM-DD). The key column is the exercise name used by `npm run fetch` / `npm run grade`.
Parts of the same exercise (5a, 5b) share the exercise number in the mails; a mail goes to the part whose publish date is the latest one on or before the mail's date.
